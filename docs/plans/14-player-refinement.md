# Plan 14: Player refinement (iOS look, configurable skip)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** make the iOS player match the design (white on Liquid Glass, one grouped top-right cluster, three-button transport), and add configurable skip back / forward (default 10 s each) on both platforms, plus an optional automatic skip of intros and recaps.

**Architecture:** the settings and the seek maths live in `shared/` (a per-profile Room column set, `ProfileSettings`, `PlaybackViewModel`), so both apps behave the same. The two native players only draw the new controls and forward taps. Phases follow the working agreement: shared, then iOS, then Android; stop for review after each.

**Tech Stack:** Kotlin Multiplatform, Room KMP (auto-migration 6 to 7), SwiftUI (iOS 16+, Liquid Glass on 26+), Jetpack Compose M3, Media3.

**Spec:** `docs/design/player.md`, plus `guardrails.md` (Playback), `ios.md`, `android.md`. Interactive mockups: the `PlayerControls`, `PlayerScreen` and `PlaybackSettings` components of https://claude.ai/artifact/HeWVw1EzAbYcvssURJ2rNc

**Status:** built on branch feature/player-refinement (2026-10-23); iOS UI checked only by build and the onboarding smoke test, not by hand

## Global Constraints

- Defaults: skip back **10 s**, skip forward **10 s**. Choices: back 5, 10, 15, 30; forward 10, 15, 30, 45, 60 (the seconds SF Symbols has a `gobackward.<n>` / `goforward.<n>` glyph for).
- Both values are per profile, stored in `account_settings` like `showHomeHero`. "Skip intros and recaps" is per profile, **off** by default.
- iOS player controls are white (`.primary`) on glass, never aqua; aqua is only the scrubber's progress. Pre-iOS 26 the same controls sit on `Brand.scrim`.
- All user-facing text goes in `Strings` first (`ui/common/Strings.kt`); native screens hold no string literals. iOS shows button and title labels in title case through `titleCased()`.
- Never auto-skip Outro / credits: they give way to up next. Auto-skip applies to Intro and Recap only, once per segment.
- A 401 still goes through `ConnectionManager.expireSession`; nothing here calls `AccountRepository.expire`.
- Commits: one line `task|fix|feat|chore: <message>`, no body, no `Co-Authored-By` trailer.
- Done = `./gradlew :shared:allTests`, `./gradlew :androidApp:assembleDebug`, and for iOS changes `scripts/ios-smoke.sh` (say plainly if a tool is missing). Player changes are also checked on the test server (`docs/test-server.md`, episode `show-e01`: Intro 0:10-0:40, Credits near the end).

## Review Focus

Inputs the design implies but no task name hides; each has a test in the owning task.

1. Skip forward near the end (or before the duration is known): clamps to the duration; with an unknown duration (0) it does nothing. Skip back near the start clamps to 0. (Task 3)
2. Two skip taps before the player has reported its new position stack (10 + 10 = 20 s), not repeat from the old position. (Task 3)
3. Auto-skip fires once per segment: seeking back into the intro does not skip again, while the button still shows. Outro is never auto-skipped. (Task 3)
4. A stored value outside the choices (an older build, a hand-edited DB) is shown and used as the default, and the setter rejects values outside the choices. (Task 1)
5. Switching profile on the same device changes the skip values with it, and a profile with no row yet gets the defaults. (Task 2)
